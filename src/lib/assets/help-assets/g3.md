Los widgets dinámicos permiten mostrar ejemplos interactivos generados por IA durante una sesión.

1. El profesor solicita un ejemplo al asistente de IA.
2. El widget se genera y se comparte automáticamente con los estudiantes conectados.
3. Los estudiantes pueden interactuar con el widget en tiempo real.

Esto usa Supabase Realtime para sincronizar el estado entre todos los participantes.
