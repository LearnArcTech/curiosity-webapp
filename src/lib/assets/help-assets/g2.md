Los salones virtuales son el espacio donde ocurre la clase.

- Cada salón tiene un código único de acceso.
- Los estudiantes pueden levantar la mano virtualmente.
- El widget de participación muestra quién ha intervenido.

Consulta con tu profesor si tienes problemas para unirte a un salón.
